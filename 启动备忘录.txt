# AI 面试项目 - 本机启动备忘录

> 环境已一次性装好，以后不需要再安装任何东西。
> PostgreSQL 已经迁到 D:\study\postgres\ ，跟项目目录完全分离，删项目不会丢数据。

## 最快启动方式（推荐）

双击：`启动项目.bat`

它会依次拉起：
1. PostgreSQL 数据库（D:\study\postgres\pgdata，端口 5432）
2. FastAPI 后端（端口 8000）— 新开独立窗口
3. Next.js 前端（端口 3000）— 新开独立窗口

然后浏览器访问 `http://localhost:3000`

## 手动启动（三个终端分别执行）

如果批处理脚本有问题，手动执行以下命令。

**终端 1 - 数据库：**
```
D:\study\postgres\pgsql\bin\pg_ctl.exe -D D:\study\postgres\pgdata start
```

**终端 2 - 后端：**
```
cd c:\Users\肖欣睿\Desktop\ai_interview-main\backend
.\venv\Scripts\python.exe main.py
```

**终端 3 - 前端：**
```
cd c:\Users\肖欣睿\Desktop\ai_interview-main\web
D:\node\npm.cmd run dev
```

## 关闭

- 前端、后端：在各自窗口按 `Ctrl+C` 即可
- 数据库：可以不手动关（关机自动停）。需要立即关就双击 `停止数据库.bat`

## 数据位置（关键！）

| 内容 | 路径 |
|---|---|
| 项目代码（可随时删） | `c:\Users\肖欣睿\Desktop\ai_interview-main\` |
| PostgreSQL 二进制（可重装） | `D:\study\postgres\pgsql\` |

| 下载的 zip 压缩包（可删） | 项目根目录 `postgresql-16-binaries.zip` |

## 常见问题

| 问题 | 解决 |
|---|---|
| 前端打不开 localhost:3000 | 看前端窗口的输出，是否 Ready 了 |
| 后端报数据库连接失败 | 先启动数据库，再启动后端 |
| API Key 没填 | 网页右上角齿轮图标，填 Smart/Fast 双通道 key |
| node/npm 找不到 | 路径是 `D:\node\`，不是标准路径 |
