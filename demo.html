Highlights

技术亮点

项目开发中的工程实践亮点

01

LangGraph 状态机编排

使用 LangGraph 构建面试流程、简历优化、简历生成三套独立的状态机工作流，实现复杂 Agent 逻辑的可视化编排与可控执行。

02

多智能体圆桌协作

简历优化采用「圆桌会议」模式，三个专家 Agent 并行分析后由 Reflector 节点进行元反思与精炼，模拟真实团队协作决策。

03

全链路流式传输

从 LLM 推理到后端 API 到前端渲染，全链路 SSE 流式传输。语音面试额外支持音频流 + 文本流双通道实时响应。

04

前端音频工程

浏览器端集成 VAD 语音活动检测与 STT 语音识别，IndexedDB 本地音频缓存支持离线多端持久化播放，Web Audio API 实时处理。

05

容器化一键部署

Docker Compose 编排 4 个服务（PostgreSQL + Backend + Frontend + Nginx），支持 Render 云平台免费部署，CI/CD 友好。

06

Smart/Fast 双通道模型

根据任务复杂度动态选择模型：复杂推理用 Smart Model (GPT-4)，简单任务用 Fast Model (GPT-3.5)，兼顾质量与成本。
